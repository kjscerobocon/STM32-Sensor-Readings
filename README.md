# STM32 Sensor Readings

A collection of STM32 firmware examples for reading data from sensors. Use these examples to learn how to connect a sensor, collect readings, and check how those readings change as you test it.

## Getting Started

1. Choose an example and check which STM32 board and sensor it uses.
2. Check the sensor’s supply voltage and connect it using the pin assignments for that example.
3. Open the project in the development environment used for the example.
4. Build and flash the firmware to your STM32 board.
5. Check the readings using the output method provided by the example.

## Adding an Example

Include the STM32 board name, sensor model, wiring, and instructions for viewing the readings. If the code converts raw readings to units, note the expected units.
